Faire un CV lisible par les logiciels de tri (ATS)

Dans les grandes entreprises et sur les sites d'emploi, ton CV est souvent lu d'abord par un logiciel de suivi des candidatures, appelé ATS. Il en extrait le texte, le range dans des cases et le compare à l'offre. Si ton CV est mal lu, il peut être écarté avant qu'un humain ne le voie.

1. Une mise en page simple

Une seule colonne se lit le mieux. Évite les tableaux, les zones de texte et le texte dans les images : beaucoup de logiciels les lisent dans le désordre ou les ignorent. Les modèles Classique et Élégant de CV.express sont pensés pour cela : tout le texte est un vrai texte, dans le bon ordre.

2. Des titres de rubriques standard

Le logiciel reconnaît les rubriques à leur titre. Utilise les noms attendus : « Expériences professionnelles », « Formation », « Compétences », « Langues ». Un titre original comme « Mon parcours » risque de ne pas être compris.

3. Les mots-clés de l'offre

Relis l'offre d'emploi et repère les mots importants : intitulé du poste, logiciels, techniques, diplômes demandés. Reprends ceux qui correspondent vraiment à ton profil, avec les mêmes mots. Si l'offre parle de « comptabilité fournisseurs », écris « comptabilité fournisseurs », pas seulement « comptabilité ».

4. Des dates claires

Indique un mois et une année pour chaque expérience (« mars 2022 – aujourd'hui »). Le logiciel calcule ainsi ton nombre d'années d'expérience, souvent utilisé pour trier.

5. Un PDF avec du vrai texte

Envoie un PDF créé à partir d'un texte, pas une photo ou un scan de ton CV : le logiciel n'en tirerait rien. Pour vérifier, ouvre ton PDF et essaie de sélectionner une phrase : si tu peux la copier, le logiciel peut la lire. Les PDF de CV.express sont toujours faits de vrai texte.

Le modèle Classique est le plus sûr pour les logiciels de tri. Tu peux aussi importer ton ancien CV pour vérifier comment il est lu.
